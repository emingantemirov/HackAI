# Demo-Leitfaden (ca. 10 Minuten)

Vorbereitung: `npm run demo:reset`, Server mit `DEMO_AI_MODE=true` und `WEB_DIST` starten. Anmeldung mit mehreren Rollen in getrennten Browserfenstern (siehe README).

1. **Übersicht** (Fachbearbeitung): 17 Kriterien als Entwurf, 7 offene Klärungsvorgänge. Jede Zahl öffnet die gefilterte Liste. Unten der Betragsvergleich 2.140,50 € / 2.104,50 € / −36,00 € – deutlich als *Demonstration* gekennzeichnet.
2. **Kriterien → Quellen**: Quelle öffnen, Hashwert und Fundstellen zeigen, „Eingebettete Kriterien übernehmen“ erklären. Kriterium K-001 öffnen: wörtlicher Beleg mit Fundstelle, Abkürzungen per Tooltip.
3. **Klärungsvorgänge** (Prüfer): Sechsmonatsgrenze entscheiden – mit Begründung. Das Portal entscheidet das nie still.
4. **Freigabe**: Fachbearbeitung reicht K-001 ein; Prüfer lehnt **ohne** Begründung nicht ab (Button gesperrt), lehnt mit Begründung ab. Version 1 bleibt, Überarbeitung wird Version 2. Eigene Einreichung freigeben geht nicht (Vier-Augen).
5. **Testfälle**: aus freigegebenen Kriterien erzeugen; Soll mit Herleitung ansehen; freigeben (Soll gehört zur Freigabe).
6. **Prüfungen**: neue Prüfung mit Profil „Portal-Simulator“, Testfälle hinzufügen, Paket erzeugen (ohne Soll). Simulator mit „Falsches EFZ-Ende“ ausführen.
7. **Testlauf T-019** (mehrstufig, AZVU 1234-5678-007): Soll/Ist-Tabelle, Abweichung in rot (Text + Icon), Klick auf „Zeile n“ zeigt die Rohdaten mit Markierung. Abweichung ≠ bestanden.
8. **Bericht** erstellen → einreichen → freigeben (zweite Person) → bereitstellen. Versand per E-Mail zeigt ehrlich „nicht konfiguriert“.
9. **Zertifizierung**: Voraussetzungen als Checkliste; „Bestanden“ ist nicht „Zertifiziert“; Entscheidung mit Begründung und Hinweis, dass es keine amtliche Zertifizierung ist.
10. **Hersteller** (kunde@): nur eigene Prüfung, kein Soll, nur bereitgestellte Berichte.
